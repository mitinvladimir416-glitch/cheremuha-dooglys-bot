# Черёмуха Street — система управления

Полная система учёта для кафе "Черёмуха Street": Telegram-бот, backend API, PostgreSQL, интеграция с Dooglys и веб-панель (React).

## Состав проекта

| Папка/файл | Что это |
|---|---|
| `backend/` | Express API — авторизация, работа с БД, дашборд, продажи |
| `bot/` | Telegram-бот (aiogram) — интерфейс для сотрудников |
| `frontend/` | React веб-панель (в разработке) |
| `init.sql` | Схема PostgreSQL |
| `docker-compose.yml` | Локальный запуск всех сервисов одной командой |
| `backend.Dockerfile`, `bot.Dockerfile` | Контейнеры для деплоя |
| `.github/workflows/deploy.yml` | Автодеплой backend на Railway при пуше в main |

## Безопасность

- Все секреты — только в `.env` (не в git) или в панелях Railway/Vercel/GitHub Secrets.
- `.env.example` — шаблон без реальных значений, безопасно коммитить.
- Пароли пользователей хранятся хэшированными (bcrypt), никогда в открытом виде.
- Доступ к API — по JWT-токену, права разграничены по ролям (admin/manager/staff/cashier).

## Роли пользователей

- **admin** — полный доступ, управление пользователями
- **manager** — товары, рецептуры, отчёты
- **staff** — просмотр остатков, ввод продаж
- **cashier** — только продажи

Подробности запуска — в `QUICK_START.md`.
